# paginas-clientes

Una carpeta por cliente, copiada de `plantilla/`. Cada página es un solo `index.html`; los datos del negocio se cambian en el bloque `NEGOCIO` al inicio del archivo.

En Vercel: importar este repo y poner **Root Directory** = carpeta del cliente (ej. `yaelisa`). Un proyecto de Vercel por cliente.
